# 🌐 Portafolio — Camilo García

Mi portafolio personal: una página web de una sola vista donde muestro quién soy, qué sé hacer y los proyectos en los que he trabajado. Está hecha con **HTML, CSS y JavaScript puro**, sin frameworks, y es totalmente responsive.

🔗 **En vivo:** https://camilogarcia079.github.io/portafolio/

---

## ¿Qué incluye?

- **Inicio** — presentación y rol.
- **Sobre mí** — mi formación en Campuslands y hacia dónde quiero crecer.
- **Habilidades** — mis tecnologías y herramientas.
- **Proyectos** — mis trabajos más fuertes, con enlace a cada repositorio.
- **Contacto** — correo, LinkedIn y GitHub.

---

## 🛠️ Tecnologías

| Herramienta | Para qué |
|-------------|----------|
| **HTML5** | Estructura semántica de la página |
| **CSS3** | Diseño responsive y estilos |
| **JavaScript** | Menú móvil y animaciones al hacer scroll |

Sin frameworks ni librerías: todo está hecho a mano para tener control total del resultado.

---

## 📂 Estructura

```
portafolio/
├── index.html        → estructura de la página
├── css/styles.css    → estilos y diseño responsive
├── js/main.js        → menú móvil y animaciones
└── assets/foto.jpg   → foto de perfil
```

---

## 🚀 Cómo verlo en local

Abrir `index.html` en el navegador, o servirlo con un servidor local (por ejemplo Live Server de VS Code).
